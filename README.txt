自然拼读打靶 — 使用说明
========================

一、怎么打开
1. 用电脑或手机打开本文件夹里的 index.html
2. 推荐浏览器：Google Chrome、Microsoft Edge，或 Safari（iPhone 需 iOS 14.5 及以上）
3. 电脑可直接双击文件；也可把文件拖进浏览器窗口
4. 手机 Safari：用「文件」App 找到 index.html，用 Safari 打开；或通过同一 Wi‑Fi 下的简易本地服务打开（部分机型对 file:// 麦克风有限制）

二、允许麦克风
1. 点击「开始」进入游戏后，再点大麦克风按钮
2. 浏览器会弹出「是否允许使用麦克风」——请选择「允许」
3. 若误点拒绝：
   - Chrome / Edge：点击地址栏左侧小锁或信息图标 → 网站设置 → 麦克风 → 允许，然后刷新页面
   - Safari（iPhone）：设置 → Safari → 麦克风（或该网站设置）→ 允许，再重新打开页面
4. 尽量在较安静的环境，对着手机/电脑说清楚英语单词

三、怎么玩（简要）
1. 屏幕上会出现 4～6 个彩色目标，每个下面有英语单词
2. 下方有一颗彩色球，颜色与某一个目标相同（默认会显示要说的提示词）
3. 点击麦克风，用英语说出该单词；说对了球会飞过去并得分，说错了会飞偏，可再试
4. 「下一组」可换一批新词；词库用完后会自动重新打乱

隐私：本页使用浏览器自带的语音识别，声音可能由浏览器厂商处理；页面本身不上传、不保存录音。
无需联网加载游戏素材（仅语音识别可能需网络）。
